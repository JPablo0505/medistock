# MediStock Design System

Reference Image:
products-portfolio.png

The attached image is the primary visual reference.

Requirements:

- Preserve the visual style.
- Preserve the card-based inventory view.
- Preserve spacing and visual hierarchy.
- Preserve left sidebar layout.
- Preserve top search/filter bar.
- Use rounded corners.
- Use subtle shadows.
- Use premium SaaS aesthetics.

Do NOT:

- Convert products into tables.
- Generate a generic admin dashboard.
- Use Material UI default styles.
- Use Bootstrap styling.
- Add medical crosses or hospital imagery.

Product cards must show:

- Image
- Product Name
- SKU
- Current Stock
- Next Expiration Date
- Status Badge

Design inspiration:

- Linear
- Stripe
- Vercel

The final product should feel like a premium inventory platform for pharmacy chains.
